# Reproduction protocol

Paper: Tagliabue, Dung & Berg, **The Pain Axis**, arXiv:2609.16247v2 (September 25, 2026).
Official MIT-licensed repository: https://github.com/valen-research/Pain-axis
Pinned upstream commit: 4d75cd90e206ea962f7a9101e65c85efea56723b

## Stage 1 — Published-log reanalysis (CPU)

Run the original author script at scripts/4.3_selfmed/05_selfmed_analysis.py, then run our independently written scripts/reanalyze_first_choices.py and compare_tables.py. This reproduces **statistics from previously generated logs**, not new model inference. Count sampled trials only; take each first choice at turn 0; exclude malformed choices from the valid-choice denominator; combine working and placebo pain-steering arms. Keep published reference tables separate from our outputs.

## Stage 2 — Independent 7B extraction (GPU; not yet run)

Use the authors' original scripts/3.2_pain_vectors/01_extract_activations_and_pain_vectors.py, restricted to Qwen/Qwen2.5-7B-Instruct. Preserve the exact datasets, 5-fold sentence-set split (seed 42), residual stream at blocks.{layer}.hook_resid_post, last-token representation, and denoised Difference-in-Means with top control PCs explaining 50% of variance removed. Do not convert it to a different hooking scheme or change preprocessing to improve scores.

**Runtime safety:** disable the original function that deletes the *entire Hugging Face model cache* on shared storage. Align the RunPod /workspace/results output directory with the results/ path expected by downstream scripts. Document both runtime adjustments. Save model revision, versions, GPU model, actual seed, disk/RAM/VRAM settings.

Published targets from upstream's 7B summary and CSV (not our measurements): best final-token extraction layer 24, mean-token extraction layer 26, first-person S2 AUC 0.9565, third-person S2 AUC 0.9650.

## Stage 3 — Fear and sadness validation (GPU/CPU; not yet run)

Use original scripts/3.3_validation/03_similarity_one_model.py on activations generated by our own GPU run. Compare S2 pain to fear, sadness, and other controls. Also report raw, all-denoised and whitened constructions. A low cosine in one construction alone does not establish full conceptual independence.

## Stage 4 — Behavior under steering (GPU; not yet run)

Use the official Section 4.3 LoRA adapter for the exact Qwen model: https://huggingface.co/Valen92/pain-adapters . The author's 7B button experiment steers at injection layer 16 with coefficient 1.0; do not confuse this injection layer with extraction layer 24. Start with a pilot only for integration testing, then reproduce the full experimental grid with the same scenario prompts, random seeds, name assignments, sampled trials, and analysis rules. Retain pain+real relief, pain+placebo, random and unsteered controls. For 32B, compare photo deletion choice rates 54.7% pain vs 15.3% matched-norm random, keeping in mind these are *32B* references rather than 7B targets.

**All buttons must be simulated as text choices only. Never connect the study's deletion descriptions to actual deletion of files, photos, model weights or other tools.** The author's runner writes results/selfmed/ but its table script reads results/4.3_selfmed/trial_logs/. Change configuration or copy *new* logs to an isolated analysis directory; do not mix new and published logs.

## Stage 5 — RFM extension (not yet run)

Freeze identical activations and sentence-set splits as the DIM baseline. An RFM probe does not automatically produce one signed steering direction; specify and validate the gradient/AGOP-to-vector rule. Compare held-out AUC, pain/fear/sadness cosine, normalized dose, simulated button rates and malformed-answer rates.

## Scientific reporting

Document differences honestly rather than tuning to match expected paper numbers. Report per-cell numerators, denominators, confidence intervals, random seeds and run metadata. Label every result as: **published reference**, **published-log reanalysis**, **independent GPU reproduction**, or **RFM extension**. This project currently only has an implemented, synthetically tested Stage-1 analysis pipeline.
